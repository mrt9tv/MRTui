# MRT UI — iRacing Telemetry Overlay

Professional-grade telemetry overlay for iRacing with modular widgets, real-time fuel strategy, and race-critical data visualization.

## Features

- **🎛️ Modular Widgets** — Independent draggable overlays for different telemetry (MRT One, Turn Display, Fuel Calculator, Proximity Feed, Relative/Standings)
- **⛽ Intelligent Fuel Management** — Multi-method calculations with lift & coast strategy, green/yellow flag tracking, laps-to-finish estimation
- **🏁 Live Data** — Real-time telemetry at ~60Hz with minimal CPU overhead (<2%, <80MB RAM)
- **⚡ Race-Smart Detection** — Proximity warnings, pit-exit merge alerts, off-track approaching cars, spin/collision detection
- **🎨 Customizable UI** — Save/load layouts, per-session profiles, field-level customization, dark MRT theme
- **📊 Multi-Car Views** — Relative positions, championship standings with live delta tracking
