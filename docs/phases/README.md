## 🎨 Design Standards

All phases follow the **MRT Design System**:
- **Colors:** Teal (#008080) + Orange (#FF8000)
- **Style:** Minimalist, compact, professional
- **Spacing:** 15px standard margins
- **Typography:** 14-16px body, 18-24px headers
- **Icons:** Emojis or simple symbols

See [Color Palette & Design Strategy.md](../Color%20Palette%20&%20Design%20Strategy.md) for complete guidelines.
